# Roomscape capture checklist

Print this page or keep it beside the phone. A steady, well-lit, overlapping walkthrough gives the reconstruction the best chance of success.

## Before recording

- [ ] Turn on room lights and open curtains. Avoid dark corners, moving people, mirrors, reflective glass, and changing screens.
- [ ] Clear loose clutter from the floor and paths. Keep distinctive furniture and wall details visible; avoid moving objects during capture.
- [ ] Place a flat, clearly visible AprilTag with known printed size (configured default: 20 cm) on a wall. Keep it in view from several positions and angles. Do not bend or cover it.
- [ ] Connect rooms with a continuous path through doorways. Keep doors in a fixed position.

## Phone setup

- [ ] Use the main rear camera lens only; do not switch lenses or zoom while recording.
- [ ] Set 4K resolution at 30 fps when available. Use the standard video mode.
- [ ] Lock auto exposure and autofocus (AE/AF) after framing; turn HDR off.
- [ ] Clean the lens, hold the phone horizontally, and keep the same orientation throughout.
- [ ] Start recording before entering the space. Walk slowly and keep the camera steady at chest height.

## Walk pattern

- [ ] Make one perimeter pass around each room, keeping walls and corners in view.
- [ ] Add a slow lawnmower/zig-zag pass through larger rooms so the center and floor are captured from multiple viewpoints.
- [ ] Overlap each view with the previous view by roughly 60–80%; keep some recognizable features in every successive frame.
- [ ] Turn slowly in an arc. Avoid spinning in place, fast pans, and abrupt stops.
- [ ] Pass through each doorway slowly, showing both sides of the transition. Continue into the next room without stopping the recording.
- [ ] Close the loop by returning near the starting area with overlapping views.
- [ ] Keep floors, room corners, and any scale marker visible in multiple frames.

## After capture

- [ ] Check that the video plays, is not blurred, and contains the complete connected route.
- [ ] Run the quick-start command from the repository README. If registration is poor, add overlap/light or recapture more slowly; review `report.md` and the stage logs for the precise failure.
